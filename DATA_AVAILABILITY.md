# Data Availability

## Public datasets

The public portion of the study dataset contains 1,096 images from two sources:

- **Roboflow StampDet, version 10:** 732 images with the annotations supplied by the public dataset.  
  https://universe.roboflow.com/marcos-7aslt/stampdet/dataset/10
- **Kaggle StaVer:** 364 selected images that were manually annotated for the study.  
  https://www.kaggle.com/datasets/rtatman/stamp-verification-staver-dataset

The images remain subject to the access conditions and licenses stated by their original providers.

## Enterprise-provided invoice images

The self-constructed portion contains 500 real invoice images supplied by a collaborating enterprise. These images contain confidential invoice information and are subject to confidentiality and third-party restrictions. The authors are not authorized to publish or redistribute the complete enterprise dataset.

Fifteen representative sample images that have been approved for sharing will be provided separately through Baidu Netdisk:

**Seal_datasets_samples:** Baidu Netdisk URL: https://pan.baidu.com/s/1B0jLWgPrjiTW4vfstwsCHw 
- **Access code:** pyds.

The remaining enterprise images cannot currently be distributed by the authors, including through an author-managed request procedure. No non-author contact is listed because the data provider has not established a public external-access process for these restricted images.

## Materials in this repository

This repository provides the ISD-YOLO source code and model configuration. It does not contain the enterprise invoice images, trained weights, or the complete study dataset. The public dataset links above and the Baidu Netdisk entry for the 15 approved samples define the currently available image data.
